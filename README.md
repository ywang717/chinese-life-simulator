# 中文人生模拟器 · 人生手记

一个无需登录、手机优先的中国城市纯文字人生模拟游戏。

## 分支约定

- `main`：稳定分支。
- `develop`：日常开发分支（保留原项目约定）。
- `feature/life-simulator-v01`：首个可运行版本，通过草稿 PR 审阅后再合并。

## 运行

需要 Node.js 22 或以上，无第三方运行依赖，无需安装包。

```sh
npm start
```

浏览器访问 `http://localhost:3000`。也可以把 `dist/` 放到任意静态网站托管服务。请通过 HTTP/HTTPS 访问，不要直接双击 HTML 文件。

```sh
npm test
npm run build
```

`build` 检查所有模块语法、模块引用与页面资源；原生浏览器模块无需编译打包。静态站点源码位于 `dist/` 并被 Git 跟踪，不能当作可删除的生成目录。

## 已实现

- 13 城市、21 职业框架、19 爱好、12 社团、107 条样例事件。
- 固定种子人物与年度事件；属性不限 0～100，概率使用软饱和。
- 每年一个主事件，普通年份直接推进，关键年份选择；条件过滤、权重解释、冷却与类别重复抑制。
- 父母衰老、教育、资格、长期人物关系、工作与转行、副业、婚恋子女、自然迁居。
- 工资和支出、房产与房贷、卖房出租及提前还贷、简化投资、创业、赌博长期后果。
- 标签、计数、记忆、关系、未来预约、社会履历；工伤康复与转行、十年后合作。
- IndexedDB 保存当前人生、历史、检查点与解锁记录；LocalStorage 保存字号设置。
- 每局一次时光倒流；死亡后中文人生报告，多维评价与称号。

## 架构

`state/player.js` 创建初始状态。

`engine/year.js` 按年龄→世界→财务→自然变化→家庭关系→城市→预约→筛选→主事件→效果→记忆→履历→年末的顺序推进。界面收到年末状态或待选状态后执行存档。

`engine/event.js` 只筛选并生成声明式效果；`engine/effect.js` 是状态变化的统一入口；长期后果委托 `engine/memory.js`。

`data/` 保存中文映射、城市、职业、爱好、社团与事件。新增事件须明确硬条件、权重来源、冷却、效果与后果。

## 开发复现

页面地址追加 `?debug=1`，创建人物时可输入固定种子；人物页可导出中文命名的调试日志文件。文件内部保留开发字段，正常玩家界面不展示这些字段。

日志包含年度初末状态、候选事件权重与原因、选择、即时效果及长期后果。相同种子、创建选项与选择序列可以复现。算法/事件版本改变后不保证跨版本结果完全一致。

## 游戏参数与边界

- 金额统一人民币元，总资产显示资产减负债的净值。
- 城市工资、成本、房价、市场周期均为虚构平衡参数，不对应真实行情。
- 赌场只在特定事件出现，澳门场景限制为 21 岁及以上；不提供现实下注策略，参与具有负期望。
- 退休年龄 60 岁是当前游戏约定，非现实政策模拟。
- 死亡综合年龄、健康、疾病、职业风险和意外，不以健康小于等于零直接判定。
- 第一阶段采用简化职业与教育框架；继续教育事件抽象学习过程，并不精确模拟课程学制。
- 七条路线测试使用明确的前置状态，验证因果链；另有七个种子的自然完整人生模拟，不保证每局都走到指定路线。
- 浏览器存档与设备绑定，清除网站数据会丢失；不含账号、云同步或跨设备存档。
- 已完成桌面 Chrome 试玩、375 像素有效视口排版、IndexedDB 刷新续档及一次回退验证；手机真机与 Safari 尚未验证。详见 `docs/QA.md`。
