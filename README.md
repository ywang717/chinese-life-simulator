# 中文人生模拟器

一个中文网页人生模拟游戏项目。

## 分支约定

- `main`：稳定分支
- `develop`：日常开发分支

## 核心玩法

- 每年推进一次人生
- 普通事件自动结算，关键事件由玩家选择
- 属性允许低于 0 或高于 100
- 突发事件可造成大幅属性变化
- 部分人生事件可触发转行
- 爱好由先天随机与成长环境共同影响
- 特定人生节点可进入赌博/赌场系统
- 人生重大节点可自然迁居，包括郑州等城市

## 开发原则

- 游戏界面与文案默认使用中文
- 事件、职业、城市、爱好与人生阶段采用数据驱动设计
- 优先保持依赖少、结构清晰、方便 Codex 持续开发

详细需求见 `docs/PRD.md`。
