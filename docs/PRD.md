# 中文人生模拟器 PRD

## 1. 产品定位
中文网页人生模拟游戏。玩家从出生开始逐年推进人生，通过属性、事件、职业、城市、爱好、关系与随机性形成不同人生轨迹。

## 2. 核心循环
1. 进入新年龄/新年份。
2. 系统结算基础变化与普通事件。
3. 关键事件出现时由玩家做选择。
4. 选择改变属性、关系、职业、城市、爱好、资产或后续事件权重。
5. 进入下一年，直到人生结束并生成总结。

## 3. 属性系统
- 属性不强制限制在 0–100，可低于 0 或高于 100。
- 建议基础属性：健康、智力、魅力、情绪、金钱、家庭关系、社会关系。
- 极端值可触发特殊事件、状态或结局。
- 突发事件允许造成大幅属性变化。

## 4. 事件系统
- 每年必须至少发生事件。
- 普通事件自动结算，不要求玩家操作。
- 只有关键事件需要玩家选择，减少操作疲劳。
- 事件支持：年龄、属性、职业、城市、爱好、关系、历史事件、前置选择等条件。
- 事件结果可改变属性、状态、事件权重并解锁后续事件链。

## 5. 职业系统
- 职业由教育、能力、城市、家庭背景与随机机会共同影响。
- 部分人生事件后允许转行。
- 转行应有机会成本、收入波动和成长空间差异。
- 职业可形成晋升、失业、创业、转行、退休等路径。

## 6. 城市系统
- 城市影响工资、房价、生活成本、教育、职业机会与事件池。
- 初始及可迁居城市包含郑州。
- 玩家不应频繁手动切城，而是在升学、就业、结婚、买房、创业等重大节点自然触发迁居机会。
- 不同城市应形成明显生活体验差异。

## 7. 爱好系统
- 爱好具有先天随机倾向。
- 成长环境、家庭、学校、朋友和城市会改变爱好形成概率。
- 爱好可提升属性、社交、职业机会或产生支出。
- 长期投入可形成技能等级、圈子与特殊事件。

## 8. 赌博系统
- 仅在符合年龄与特定人生节点时出现。
- 玩家可以选择是否进入赌场/赌博场景。
- 结果具有明显随机性，可带来巨大收益或损失。
- 连续参与可增加高风险事件和负面状态概率。
- 赌博应作为高风险人生分支，不成为稳定赚钱手段。

## 9. 随机与突发事件
- 包括疾病、事故、失业、意外收入、贵人、家庭变化、社会环境变化等。
- 允许单次事件大幅改变人生轨迹。
- 随机不应完全无因果，尽量受玩家当前状态与历史选择加权。

## 10. 人生阶段
建议阶段：童年、学生期、初入社会、事业发展、成家阶段、中年、晚年。
不同阶段拥有独立事件池与决策密度。

## 11. 体验原则
- 中文界面与中文文案。
- 单局以可反复游玩为核心。
- 普通年份推进快，关键节点放慢。
- 不追求每年大量选择，重点是重要选择产生长期后果。
- 强调人生不可控性，但保留玩家长期策略空间。

## 12. 技术方向
- 事件、职业、城市、爱好等优先数据驱动。
- 核心逻辑与 UI 分离。
- 随机数支持种子，便于测试和复现。
- 所有数值规则集中管理，避免散落在组件中。
- 初期先完成可玩的单机网页 MVP，不优先开发账号、联网、排行榜和商业化系统。

## 13. MVP
首版至少实现：
- 出生与基础属性生成
- 年龄推进
- 普通/关键事件
- 选择与属性变化
- 教育与职业
- 转行
- 城市与迁居
- 爱好
- 赌博事件
- 随机突发事件
- 死亡条件
- 人生总结

## 14. 开发优先级
P0：人生推进、属性、事件、选择、存档基础。
P1：教育、职业、城市、爱好、关系。
P2：赌博、复杂事件链、成就、更多城市与职业。
P3：表现层、动画、统计、扩展内容。
